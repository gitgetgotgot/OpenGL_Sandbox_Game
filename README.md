# C++-OpenGL-Sandbox-Game

Custom engine written in C++ and OpenGL for simple 2d sandbox game, inspired by Terraria.</br>
Uses CMake & Conan for build.</br>
Also has built-in mods system.</br>
This engine should be considered as a pet-project.

# Used libraries

GLFW - window, input/output
GLM - math
nlohmann_json - serialization
stb - image load/save
miniaudio - sounds/music
GLAD - OpenGL loader
</i>msdfgen probably will be added later for MSDF text</i>
